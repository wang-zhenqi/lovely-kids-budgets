# 理论碎片

一条碎片是读到或在家里看到的一句主张，还不能指导正式需求。文件名是 `YYYY-MM-DD-短题.md`。

每篇写这四项：

- 来源：书、文章、链接，或家里的哪一次使用。家长经验帖和有对照的研究要标明是哪一种。
- 年龄：主张适用的年龄。涉及芊芊、万万时写下当时的年龄。
- 主张：一句话。
- 可能影响的问题：它将来可能归进哪一篇文章，例如水位、钱如何到来、交换。

同一问题已有文章，或这已是第二条碎片时，把主张收进 `docs/theory/` 下的那篇文章，来源改记在文章里，然后删除本目录中的碎片。过程见 [如何记下理论](../如何记下理论.md)。
