# 记账

本领域包含记账、账本、金额、备注。

## 适用任务

改记账记录、账本界面、金额或备注时，只读本文件，以及下面列出的正式文档。

## 代码入口

`index.html` 的 `state.logs`。账本是元素 `#ledgerSheet`。金额是输入 `#amount`，备注是输入 `#note`。

## 正式文档

尚无。新文档放在本目录，并在 `docs/INDEX.md` 的对应行填上路径。

## 不读

其他领域、`docs/inbox/`、`docs/archive/`。消费分类的定义在 `categories`。余额的归属在 `kids`。
