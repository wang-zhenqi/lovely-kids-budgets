# 进行中的设计与计划

brainstorming 把设计说明写到 `specs/YYYY-MM-DD-<topic>-design.md`。写计划的技能把实现计划写到 `plans/YYYY-MM-DD-<feature-name>.md`。路径和文首沿用这两个技能的默认格式。

这些文件是原料。只有正在执行的那一篇可以打开。

工作结束时，把其中的意图写入正式需求，把已经成立的行为写入领域文档，把取舍写成 ADR，然后删除设计说明和实现计划。这里不保留已完成清单。
