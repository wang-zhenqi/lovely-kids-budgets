# 芊芊和万万的存钱罐

给芊芊和万万记日常花费的单页工具。每个孩子有自己的预算和余额。花一笔钱，就从当前孩子的存钱罐里减去，并记进账本。

用浏览器打开仓库里的 `index.html` 即可使用，不需要安装或构建。页面按手机尺寸设计，也可以加到主屏幕。

## 现在可以做什么

页面上方是两个孩子。点一下切换当前孩子。名字旁边的数字是预算，默认 ¥50，可以直接改。存钱罐里的数字是余额，水位随余额相对预算的高低变化。

从存钱罐拖一枚硬币到某个消费分类上，填写金额和可选备注，确认后记一笔账。金额不能超过当前余额；余额为 0 时不能再记。备注最多 20 个字。

默认的消费分类是零食、玩具、书本、游戏和冷饮。可以添加分类：名称最多 6 个字，并选一个图标。长按已有分类可以改名称、换图标或删除。把硬币拖到「添加」上，会先新建分类，再建账。

点「账本」查看记录，新的在上面。每条显示是哪个孩子、哪个消费分类、备注、时间和金额。向左滑出删除。删掉一条后，金额加回那个孩子的余额。

改预算时，已经花掉的金额保持不变，余额变成「新预算减去已花金额」，且不会低于 0。例如预算 50、余额 10（已花 40），把预算改成 60，余额变为 20。

这些内容都保存在当前浏览器的本地保存里，键名是 `lovely-kids-budget-v1`。换一台设备、换一个浏览器，或清除这个网站的数据，记录就不会还在。
